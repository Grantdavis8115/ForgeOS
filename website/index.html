Features

ForgeOS highlights

Minimal and clean, with smooth motion, rounded glass surfaces, and crisp typography.

🧰 Custom ForgeOS installer

A guided ForgeOS installer inspired by Calamares, with a polished setup flow for fresh installs and upgrades.

🎨 Custom desktop theme

A bespoke ForgeOS theme with graphite surfaces, glass panels, and a refined macOS-inspired desktop.

💿 Custom boot splash

Integrated Plymouth branding for a signature ForgeOS boot experience from power-on to login.

🛍 ForgeOS app store

A complete application store with Microsoft Store apps, Apple Store apps, and ForgeOS-native tools.

🔄 Automatic updates

Secure background updates keep the OS, apps, and security tools current without interrupting your workflow.

🔐 Expanded security tools

Additional security tooling, hardening presets, and a built-in dashboard for daily protection.

🖥 Custom desktop shell

A ForgeOS shell with a refined launcher, dock, and terminal experience tailored to power users.

Installation

Install ForgeOS

Download the latest ForgeOS image, verify the SHA256 checksum, and follow the guided installation steps for desktop and virtual machines.

Minimum requirements

  • 4 GB RAM
  • 20 GB storage
  • UEFI or legacy boot support

Getting ready

Create a bootable USB, back up your files, and choose the ForgeOS stable image for the most polished experience.
