Installing ForgeOS

Download the ISO from the Download page, verify the SHA256 checksum, then create bootable media with Etcher, Rufus, or dd.

  1. Boot from USB or DVD
  2. Select “Install ForgeOS” from the live environment
  3. Partition disk and create a user account
  4. Reboot and remove installation media

Dual Boot

Reserve a separate partition for ForgeOS. Disable Fast Startup on Windows, shrink an existing volume, and install the bootloader to the EFI system partition when prompted.

VirtualBox

Create a new VM with 4 GB RAM, 2 CPU cores, and a 40 GB virtual disk. Enable EFI if your host supports it. Attach the ForgeOS ISO and install as you would on bare metal.

VMware

Use “Create a New Virtual Machine”, select the ISO, and choose Linux > Ubuntu 64-bit. Allocate at least 4 GB RAM and enable 3D acceleration for the GNOME desktop.

Updating ForgeOS

Apply system updates from Settings or the terminal:

sudo apt update && sudo apt upgrade -y

Installing Packages

Browse the Packages catalog or use the package manager: 

sudo apt install firefox

Terminal Commands

  • forge-update — check for ForgeOS-specific updates
  • forge-security-scan — run a quick security audit
  • systemctl status — inspect system services

Troubleshooting

If the system fails to boot, try recovery mode from GRUB. For display issues, boot with nomodeset. Visit Support to report bugs or contact the team.
