August 1, 2026

ForgeOS 1.0 Released

Today we are shipping ForgeOS 1.0 — our first stable release combining a macOS-inspired desktop with a curated security toolkit.

New desktop

  • Refined GNOME shell with ForgeOS theme and dock
  • Updated logo and icon set across the system
  • Smoother animations and window management

Security improvements

  • Pre-configured penetration testing tools
  • Hardened default firewall profile
  • Forge Account sign-in from the welcome screen

Performance enhancements

  • Faster boot times on SSD hardware
  • Optimized package manager mirrors
  • Reduced idle memory footprint

Future plans

Up next: ARM images, expanded icon theme, nightly builds, and Donate / About pages as the project scales toward a full distribution website.
